فروشگاه موبایل - نسخه سرور-محور
===============================
پیش‌نیاز: Node.js نسخه 18 یا جدیدتر (بدون نیاز به npm install)

اجرا:
  ADMIN_PASSWORD=رمز_قوی_شما node server.js
  (اگر ADMIN_PASSWORD ندهید، رمز تصادفی یک‌بار در کنسول چاپ می‌شود)

آدرس‌ها:
  فروشگاه: /
  پنل مدیریت: /admin

فایل‌ها:
  server.js        سرور، API، سشن، امنیت، موجودی و سفارش‌ها
  data/db.json     پایگاه داده (خودکار ساخته می‌شود؛ از آن پشتیبان بگیرید)
  public/          فایل‌های نمایشی

پشت پروکسی HTTPS (Nginx و غیره): TRUST_PROXY=1 بگذارید. کوکی امن خودکار فعال می‌شود.

تنظیمات اختیاری (متغیر محیطی)
-----------------------------
ZARINPAL_MERCHANT   کد پذیرنده زرین‌پال (برای فعال شدن پرداخت آنلاین)
ZARINPAL_SANDBOX=1  استفاده از محیط آزمایشی زرین‌پال
ZARINPAL_UNIT       ضریب تبدیل تومان به واحد ارسالی درگاه (پیش‌فرض 10 برای ریال).
                    قبل از اجرای واقعی، واحد مبلغ را در مستندات زرین‌پال و با یک تراکنش آزمایشی بررسی کنید.
PUBLIC_URL          آدرس عمومی سایت، مثلاً https://shop.example.ir (برای بازگشت از درگاه)
KAVENEGAR_KEY       کلید API کاوه‌نگار برای پیامک (اختیاری)

نکته: شماره‌های مشتری باید به فرمت موبایل ایران (09...) یا با کد 98 وارد شوند.
